怎么用
1. 拖图进来即可；数字偏少往右拉「灵敏度」，偏多往左拉。
2. 左键点空白 = 加一颗；右键点颗粒 = 删掉；点颗粒会高亮。
3. Ctrl+Z 撤销手改，F 复位视图，滚轮缩放、拖拽平移。
4. 多分散：半径范围放到最松，直方图看两类；实在分不开就只调灵敏度。
5. 实测（2400×2400 稠密床，600 颗）：圆心误差中位 0.3 px；默认档数量偏少约 0–8%，
    往下调灵敏度会多出假点。导出的图会写清最终数。
