    操作说明

    • 载入　打开 review 目录（或把该目录拖进页面）会一次载入 queue 和帧图；只有浏览器不支持目录选择时才需在「手动选择」里选两个。
    • 视角　滚轮缩放，按住左键拖动平移（拖过 3 px 不会误加点）；0 适应窗口，+ / − 缩放。
    • 补检　点击空白处补一个颗粒，点击圆圈删除该颗粒；← / → 切换异常帧。
    • 参考位置　青色虚线圆是缺失颗粒的预测位置（按相邻帧推测），放好点后自动隐去，可用「参考位置」开关。
    • 「缺 N」标签　点击把画面移到参考位置；目标在画面外时标签贴在画布边缘并带箭头。
    • 进度　左侧每帧显示 缺 N / 1/2 / ✓，顶部汇总还差多少、完成几帧，防止一帧缺两颗只补了一颗。
    • 朝向　添加的颗粒只记录中心和半径；curate 会用局部暗色 marker 估朝向，失败则保持无效。
    • 继续标注　已导出过动作日志时，重新打开同一目录后点「载入已有动作」选那个 json，已补的点会回到画面，再接着补剩下的就行。
    • 保存　保存后把 review_actions.json 交给 vibrotrack curate。图片不会上传，全部在本地浏览器处理。
