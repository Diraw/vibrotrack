怎么用
1. 数字是人眼校对前的自动结果；左键加、右键删。
2. Ctrl+Z 撤销，F 复位视图，A 切到加一颗。
3. 「导出标注图」写出带圈和最终数量的 PNG。
4. 缺颗多发生在被邻居挤住的颗粒上；想更准就重跑 vibrotrack count 并把相邻帧放在同一目录。
5. 同一批数据的正式口径仍是 extract → geometry → index → accept → verify。
